# Prestige Auto Spa

A responsive marketing site for Prestige Auto Spa in Bronxville/Yonkers, NY.

## Preview

Open `index.html` directly in a browser. The site uses remote Unsplash imagery and Google Fonts, so an internet connection is needed for the full visual treatment.

## Deploy on Render

This repository includes `render.yaml` for a static Render deployment. Connect the GitHub repository in Render and choose **New Blueprint Instance**. Render will publish the project at a generated `onrender.com` URL.

## Notes

- The quote form currently confirms in the browser and is ready to connect to a booking service or email endpoint.
- Business details are based on the supplied Google Maps listing: 50 Palmer Ave, Bronxville, NY and (914) 361-1919.
- No Node.js installation is required for this static version.
